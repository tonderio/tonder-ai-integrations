# Tonder Web SDK 0.1.15

Maintenance release. Nothing a user installs changed.

## Changed

- `scripts/sync-web-sdk-skill.mjs` is now `scripts/sync-plugin-packages.mjs`, matching `scripts/sync-plugin-versions.mjs` beside it. The old name named one skill and one SDK, which stopped being true in `0.1.14` when the script began assembling every plugin package from a declared mapping. A script whose name lies costs whoever adds the second plugin the most, and that reader is the reason `0.1.14` exists.

The `0.1.14` release notes still name the old script, because that is what shipped in that release.
