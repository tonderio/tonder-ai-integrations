# Tonder Web SDK 0.1.13

Brings Apple Pay to the integration plugin and stops the bundled documentation growing with every release.

## Added

- Apple Pay integration recipe for HTML, React, and Angular, reachable through the `apple_pay` flow in `get_integration_recipe`.
- `integrate-web-sdk-apple-pay` prompt, alongside the card-payment and saved-cards prompts.
- Apple Pay guidance in the Web SDK integrator skill: check availability before rendering, the container is merchant-supplied, the payment callback is synchronous, results arrive through events, and the merchant's domain must be registered with Apple.
- A recipe drift check in `npm test`. It asserts every SDK identifier a maintained recipe names still exists in the synced README, so a rename or removal in the SDK fails here instead of reaching an integrator. It catches renames and removals, not semantic drift — a recipe using a still-existing name with an outdated pattern still passes.
- `recipes_from` in each generated `manifest.json`, so a snapshot records where its recipes came from.

## Changed

- Bundles the Web SDK `0.1.6` README snapshot from GitHub.
- Maintained recipes moved to a single unversioned source. They previously copied forward from the previous version's directory, which left the only durable copy of hand-written content inside directories whose purpose is to be regenerated and discarded.
- Only the newest documentation snapshot is kept. Pruning runs inside the sync, after the recipes are copied, so the ordering cannot be got wrong. `TONDER_DOCS_KEEP_VERSIONS` overrides the count.
- The Web SDK README resource resolves its version dynamically instead of naming one, so pruning cannot leave it pointing at a directory that no longer exists.
- Updates Claude and Codex plugin metadata for release `0.1.13`.

## Removed

- Six accumulated documentation snapshots, and the unused `plugin-runtime/` copy of the server. Nothing referenced it; both plugins run `mcp/dist/server.js`. Each plugin's bundled docs drop from 938 KB to 344 KB.
